# 工作区定时任务第一版（实施设计）

本设计替代 workspace_modules_schedule_design.md 中尚待确认的定时任务建议。

列表提供添加、编辑、暂停、恢复和删除，显示执行方式、下次时间及最近结果。
删除须二次确认并校验计划版本；只删除计划，不取消已启动任务，不删除任务或去重记录。
删除后旧批次不再启动后续任务，旧编辑和完成回写不能恢复被删除的计划。
表单选择名称、每 N 分钟（5～10080）、负责人、缺陷状态、每轮限额（1～3）、执行方式。
项目与迭代固定为所属工作区；首次保存默认暂停，明确启用后开始计时。

仅负责触发，复用 query_defects → analyze_defect/start_defect → confirm_repository。
启用计划授权选择当前工作区映射。修复继续走测试、审查、人工审批、提交、推送、Draft MR。
调度器不审批、不发布、不更改 ONES 状态。人工验证随 Draft MR 交接，不伪装为通过。

仅 TUI 运行时调度，不安装服务。每轮串行，睡眠错过的触发合并一次。
SQLite 事务保存计划和占位，编辑校验版本并重算时间；暂停不取消已经启动的任务。
连续三轮技术失败暂停，无候选不算失败；跨进程执行锁阻止重复调度。
首版保守去重：已有工作流的缺陷不自动重建；同工作区、缺陷、动作占位不重复执行。
占位后中断保留记录，需人工核查任务，不盲目重试。暂不支持按源版本自动重跑。
启动前重新取得一次性候选快照，工作区映射不匹配则拒绝执行。

验收覆盖持久化、编辑冲突、暂停恢复、错过触发、去重、失败暂停、两种入口、不自动审批。
成员和状态使用已有 ONES 筛选选项，加载失败禁止保存。
每周/每天周期、后台服务、逐轮完整历史和源版本重跑不属于首版。
